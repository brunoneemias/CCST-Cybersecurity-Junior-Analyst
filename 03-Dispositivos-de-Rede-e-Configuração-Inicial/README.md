# Módulo 1 - Design de Rede

Este módulo aborda os conceitos essenciais para projetar redes confiáveis e escaláveis, incluindo arquitetura, tolerância a falhas, QoS, segurança e endereçamento hierárquico.

---

## 🌐 Redes Confiáveis

### Principais conceitos:
- **Arquitetura**: Organização estruturada da rede para facilitar gerenciamento e manutenção.
- **Tolerância a falhas**: Implementação de redundância e caminhos alternativos para manter a rede funcionando mesmo em caso de falhas.
- **Escalabilidade**: Capacidade de expandir a rede sem comprometer desempenho ou gerência.
- **QoS (Quality of Service)**: Priorização de tráfego crítico (VoIP, vídeo, aplicações sensíveis à latência).
- **Segurança**: Controle de acesso, segmentação de redes (VLANs) e políticas de proteção.

---

## 🏗️ Projeto de Redes Hierárquicas

### Estrutura Hierárquica:
- **Core Layer**: Backbone da rede, alta velocidade, conecta distribuídos.
- **Distribution Layer**: Intermedia entre Core e Access, aplica políticas de roteamento e QoS.
- **Access Layer**: Conecta os dispositivos finais (estações, impressoras, etc.).

### Endereçamento:
- **Endereços físicos (MAC)**: Identificador único de cada dispositivo.
- **Endereços lógicos (IP)**: Permite roteamento e comunicação entre redes.

### Benefícios do design hierárquico:
- Facilita **gerenciamento e troubleshooting**.
- Melhora **tolerância a falhas** e redundância.
- Suporta **expansão futura** da rede.

---

## 💡 Dicas práticas:
1. Planejar endereçamento IP desde o início.
2. Definir camadas da rede antes de instalar equipamentos.
3. Implementar redundância para links críticos.
4. Aplicar QoS em tráfego sensível.
5. Segmentar redes para aumentar segurança.
