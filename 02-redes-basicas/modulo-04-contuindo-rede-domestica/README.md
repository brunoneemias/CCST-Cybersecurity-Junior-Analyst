# 🏠 Construindo uma Rede Doméstica

Este módulo apresenta a estrutura básica de uma rede doméstica e destaca boas práticas de segurança aplicáveis a ambientes residenciais.

---

## 🧱 Configuração Típica de Rede Doméstica

Uma rede doméstica geralmente é composta por:

- Conexão com o ISP
- Modem
- Roteador (com ou sem Wi-Fi)
- Dispositivos conectados (PCs, smartphones, IoT)

📌 O roteador é o principal ponto de controle da rede.

---

## 🔐 Boas Práticas de Segurança

- Alterar usuário e senha padrão do roteador
- Utilizar criptografia Wi-Fi forte
- Manter firmware atualizado
- Criar redes separadas para convidados e dispositivos IoT

⚠️ Dispositivos IoT mal configurados representam riscos elevados.

---

## 🖥️ Relação com Segurança de Endpoint

- Cada dispositivo conectado é um endpoint
- Endpoints comprometidos podem afetar toda a rede
- Firewalls locais e atualizações são essenciais

🔐 A segurança começa no usuário e no dispositivo final.

---

## 🎯 Objetivo do Módulo
Compreender como redes domésticas funcionam e aplicar práticas básicas de segurança para reduzir vulnerabilidades comuns.
