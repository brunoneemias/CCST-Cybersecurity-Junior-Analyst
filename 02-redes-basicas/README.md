# Módulo 02 – Redes Básicas

Este módulo faz parte da trilha **CCST Cybersecurity – Junior Analyst**.

> ⚠️ Observação:  
> O conteúdo deste módulo foi estudado e desenvolvido de forma contínua, antes da publicação no repositório.  
> Por esse motivo, os materiais estão organizados de forma consolidada.

## Conteúdos estudados
- Conceitos fundamentais de redes
- Modelos OSI e TCP/IP
- Endereçamento IP
- Protocolos de rede (TCP, UDP, HTTP, DNS, etc.)
- Noções de switches, roteadores e firewalls

## Objetivo do módulo
Construir uma base sólida em redes de computadores, essencial para a atuação em cibersegurança e análise de incidentes.
